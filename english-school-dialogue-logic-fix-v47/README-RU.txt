English Adventure — VERSION 38
ВАЖНО: это не Cloudflare Pages ZIP. Это готовая Worker-сборка.

1. Распакуйте архив.
2. На Mac нажмите правой кнопкой по deploy.command → Открыть.
3. Если macOS спросит подтверждение, нажмите Открыть.
4. В браузере войдите в Cloudflare и разрешите Wrangler доступ.
5. Дождитесь строки DEPLOYMENT COMPLETED SUCCESSFULLY.

Cloudflare обновит Worker с именем english-scholl.

В VERSION 38 исправлена логика конкретных проблемных сцен:
- сцена 4 всегда явно показывает флаг и название текущей страны;
- сцена 8 больше не оставляет пустой нижний контейнер;
- сцена 9 закрепляет вопрос за учительницей, а ответ за Незнайкой;
- сцена 10 содержит только одну карточку команды и одну кнопку действия.

Имя Дима и другие распространённые имена произносятся цельной нейросетевой
детской записью. Системный голос браузера для имени полностью отключён.

Сцена движений использует три отдельных изображения:
дети стоят, сидят на стульях или сидят на полу.
Песенка про Роя — 27-секундная композиция с мелодически изменяемой высотой
детской вокальной партии, а не чтение текста поверх фоновой музыки.

Незнайка получил отдельный чистый нейросетевой молодой мужской голос без
сильного искусственного понижения тона.

Проверка сборки: node verify-v38.mjs
Генерация голоса Незнайки: generate-v38-dunno-voice.py

Не загружайте этот архив через кнопку Create deployment в старом Pages-проекте.
